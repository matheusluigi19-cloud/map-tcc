# Edificações certificadas em Salvador

Mapa interativo e painel de dados das edificações com certificação ambiental ou de eficiência energética vigente em Salvador (BA). Trabalho de conclusão de curso, IFBA, Campus Lauro de Freitas.

Fontes: INMETRO/PBE Edifica, GBC Brasil, Fundação Vanzolini, Caixa Econômica Federal, SECIS e SEDUR. Localização geocodificada a partir do OpenStreetMap. Mapa base © Mapbox © OpenStreetMap.
